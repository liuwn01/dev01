<p><b>Length (2 bytes): </b>A 16-bit unsigned integer
that gives the length of the remaining bytes in the structure.</p>

<p><b>Id (16 bytes): </b>A 16 byte GUID that is the
value of the <b>objectGUID</b> Active Directory attribute for this address book
contact. If this field is all zeroes, this is a sentinel entry that marks the
end of the <b>ABF_CONTACTS</b> structure. The sentinel contact entry is not
included in the count of <b>ABF_CONTACTS</b> structures. The value of the <b>NumberOfAttributes</b>
field in the sentinel contact entry MUST be 0, and the <b>Length</b> field MUST
be 0x12.</p>

<p><b>NumberOfAttributes (2 bytes): </b>A 16-bit
unsigned integer that gives the number of <b>ABF_CONTACT_ATTRIBUTE</b> records
in the <b>Attributes</b> field.</p>

<p><b>NumberOfDeletedAttributes (2 bytes, optional): </b>If
the <b>NumberOfAttributes</b> field is zero, this is a deleted Contact object,
and the <b>NumberOfDeletedAttributes</b> field MUST be present if the <b>Length</b>
field is greater than 20 (0x14).</p>

<p><b>Attributes (variable): </b>Zero or more <b>ABF_CONTACT_ATTRIBUTE</b>
structures that give the requested Active Directory attributes for this address
book contact object.</p>
