# 1.1 Glossary

<p>This document uses the following terms:</p>

<p><a id="gt_e467d927-17bf-49c9-98d1-96ddf61ddd90"></a><b>Active Directory test</b>: The
Windows implementation of a general-purpose directory service, which uses LDAP
as its primary access protocol. Active Directory stores information about a
variety of objects in the network such as user accounts, computer accounts,
groups, and all related credential information used by Kerberos <a href="/openspecs/windows_protocols/MS-KILE/2a32282e-dd48-4ad9-a542-609804b02cc9">[MS-KILE]</a>.
Active Directory is either deployed as <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_2e72eeeb-aee9-4b0a-adc6-4476bacf5024">Active Directory Domain Services
(AD DS)</a> or Active Directory Lightweight Directory Services (AD LDS), which
are both described in <a href="/openspecs/windows_protocols/MS-ADOD/5ff67bf4-c145-48cb-89cd-4f5482d94664">[MS-ADOD]</a>:
Active Directory Protocols Overview.</p>

<p><a id="gt_2e72eeeb-aee9-4b0a-adc6-4476bacf5024"></a><b>Active Directory Domain Services
(AD DS)</b>: A directory service (DS) implemented by a domain controller (DC).
The DS provides a data store for objects that is distributed across multiple
DCs. The DCs interoperate as peers to ensure that a local change to an object
replicates correctly across DCs.  AD DS is a deployment of <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_e467d927-17bf-49c9-98d1-96ddf61ddd90">Active Directory</a> <a href="/openspecs/windows_protocols/MS-ADTS/d2435927-0999-4c62-8c6d-13ba31a52e1a">[MS-ADTS]</a>.</p>

<p><a id="gt_9f91b551-3c7f-4416-bd91-38f58f0b61f2"></a><b>address book contact</b>: A
user, contact, or group object that is obtained from Active Directory Domain
Services (AD DS), including a subset of the AD DS attributes that are
associated with the object, and is stored in an address book file.</p>

<p><a id="gt_b8d30ac8-0f5d-43d8-9ed8-f7067be3f800"></a><b>address book file</b>: A file
that contains a set of <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_9f91b551-3c7f-4416-bd91-38f58f0b61f2">address
book contact</a> records.</p>

<p><a id="gt_142ece82-2a9a-4f0f-8d8c-983e0d593037"></a><b>Address Book Server (ABS)</b>:
A component that produces <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_b8d30ac8-0f5d-43d8-9ed8-f7067be3f800">address
book files</a> on a daily basis.</p>

<p><a id="gt_100cd8a6-5cb1-4895-9de6-e4a3c224a583"></a><b>American National Standards
Institute (ANSI) character set</b>: A character set defined by a code page
approved by the American National Standards Institute (ANSI). The term
&quot;ANSI&quot; as used to signify Windows code pages is a historical
reference and a misnomer that persists in the Windows community. The source of
this misnomer stems from the fact that the Windows code page 1252 was
originally based on an ANSI draft, which became International Organization for
Standardization (ISO) Standard 8859-1 <a href="https://go.microsoft.com/fwlink/?LinkId=90689">[ISO/IEC-8859-1]</a>. In
Windows, the ANSI character set can be any of the following code pages: 1252,
1250, 1251, 1253, 1254, 1255, 1256, 1257, 1258, 874, 932, 936, 949, or 950. For
example, &quot;ANSI application&quot; is usually a reference to a non-<a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_c305d0ab-8b94-461a-bd76-13b40cb8c4d8">Unicode</a> or code-page-based
application. Therefore, &quot;ANSI character set&quot; is often misused to
refer to one of the character sets defined by a Windows code page that can be
used as an active system code page; for example, character sets defined by code
page 1252 or character sets defined by code page 950. Windows is now based on
Unicode, so the use of ANSI character sets is strongly discouraged unless they
are used to interoperate with legacy applications or legacy data.</p>

<p><a id="gt_108a1419-49a9-4d19-b6ca-7206aa726b3f"></a><b>attribute</b>: An identifier
for a single or multivalued data element that is associated with a directory
object. An object consists of its <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_108a1419-49a9-4d19-b6ca-7206aa726b3f">attributes</a> and their
values. For example, cn (common name), street (street address), and mail (email
addresses) can all be <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_108a1419-49a9-4d19-b6ca-7206aa726b3f">attributes</a>
of a <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_e767a471-c3fa-4e4b-a40c-daeb08f82a17">user object</a>. An <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_108a1419-49a9-4d19-b6ca-7206aa726b3f">attribute's</a> schema,
including the syntax of its values, is defined in an attributeSchema object.</p>

<p><a id="gt_6f6f9e8e-5966-4727-8527-7e02fb864e7e"></a><b>big-endian</b>: Multiple-byte
values that are byte-ordered with the most significant byte stored in the
memory location with the lowest address.</p>

<p><a id="gt_48d3e923-3081-4b1c-a8b4-db07cc022128"></a><b>contact</b>: A person,
company, or other entity that is stored in a directory and is associated with
one or more unique identifiers and <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_108a1419-49a9-4d19-b6ca-7206aa726b3f">attributes</a>, such as an
Internet message address or login name.</p>

<p><a id="gt_a70d1a05-9add-4870-ab52-ec5d939e93e2"></a><b>cryptographic hash function</b>:
A function that maps an input of any length to a short output bit string of
fixed length, such that finding an input that maps to a particular bit string
of the correct output length, or even finding two inputs that map to the same
output bit string, is computationally infeasible.</p>

<p><a id="gt_9cb45a36-92bb-4c14-b2fd-2ad7e2979bfd"></a><b>cyclic redundancy check (CRC)</b>:
An algorithm used to produce a checksum (a small, fixed number of bits) against
a block of data, such as a packet of network traffic or a block of a computer
file. The CRC is a broad class of functions used to detect errors after
transmission or storage. A CRC is designed to catch random errors, as opposed
to intentional errors. If errors might be introduced by a motivated and
intelligent adversary, a <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_a70d1a05-9add-4870-ab52-ec5d939e93e2">cryptographic
hash function</a> has to be used instead.</p>

<p><a id="gt_ee5b6fad-5c27-49d0-a20d-0eceda2baf3a"></a><b>delta address book file</b>:
An <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_b8d30ac8-0f5d-43d8-9ed8-f7067be3f800">address book file</a>
that contains only the differences between two complete address book files.
Differences can include changed values, added objects, and deleted objects.</p>

<p><a id="gt_1175dd11-9368-41d5-98ed-d585f268ad4b"></a><b>distinguished name (DN)</b>:
In the <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_e467d927-17bf-49c9-98d1-96ddf61ddd90">Active Directory</a>
directory service, the unique identifier of an object in <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_e467d927-17bf-49c9-98d1-96ddf61ddd90">Active Directory</a>, as
described in [MS-ADTS] and <a href="https://go.microsoft.com/fwlink/?LinkId=90325">[RFC2251]</a>.</p>

<p><a id="gt_dbc72c8e-9165-4ab3-88e7-bd18edf25608"></a><b>full address book file</b>:
An <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_b8d30ac8-0f5d-43d8-9ed8-f7067be3f800">address book file</a>
that contains a complete set of the <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_9f91b551-3c7f-4416-bd91-38f58f0b61f2">address book contacts</a> that
existed when the file was generated by the user, contact, and groups objects in
AD DS.</p>

<p><a id="gt_f49694cc-c350-462d-ab8e-816f0103c6c1"></a><b>globally unique identifier
(GUID)</b>: A term used interchangeably with universally unique identifier
(UUID) in Microsoft protocol technical documents (TDs). Interchanging the usage
of these terms does not imply or require a specific algorithm or mechanism to
generate the value. Specifically, the use of this term does not imply or
require that the algorithms described in <a href="https://go.microsoft.com/fwlink/?LinkId=90460">[RFC4122]</a> or <a href="https://go.microsoft.com/fwlink/?LinkId=89824">[C706]</a> have to be used
for generating the GUID. See also universally unique identifier (UUID).</p>

<p><a id="gt_7ce4771c-2043-49b8-85d3-0c60c7789f9a"></a><b>group object</b>: In <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_e467d927-17bf-49c9-98d1-96ddf61ddd90">Active Directory</a>, a <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_7ce4771c-2043-49b8-85d3-0c60c7789f9a">group object</a> has an object
class group. A group has a forward link attribute member; the values of this <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_108a1419-49a9-4d19-b6ca-7206aa726b3f">attribute</a> either represent
elements of the group (for example, objects of class user or computer) or
subsets of the group (objects of class group). The representation of group
subsets is called &quot;nested group membership&quot;. The back link attribute
memberOf enables navigation from group members to the groups containing them.
Some groups represent groups of security principals and some do not and are,
for instance, used to represent email distribution lists.</p>

<p><a id="gt_b7e2b611-0af5-4fec-8af2-3f9ce7bad205"></a><b>hash</b>: A fixed-size result
that is obtained by applying a one-way mathematical function, which is
sometimes referred to as a hash algorithm, to an arbitrary amount of data. If
the input data changes, the hash also changes. The hash can be used in many
operations, including authentication and digital signing.</p>

<p><a id="gt_6823dc32-b762-4aa0-823b-e7daa32848b1"></a><b>hash code</b>: See <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_b7e2b611-0af5-4fec-8af2-3f9ce7bad205">hash</a>.</p>

<p><a id="gt_6deb2fc7-2825-42d5-b33f-6529ea1b01f4"></a><b>in-band provisioning</b>: A
process in which a protocol client obtains configuration information from a
protocol server.</p>

<p><a id="gt_079478cb-f4c5-4ce5-b72b-2144da5d2ce7"></a><b>little-endian</b>:
Multiple-byte values that are byte-ordered with the least significant byte
stored in the memory location with the lowest address.</p>

<p><a id="gt_586971aa-3b65-4de3-be93-1a9756777d89"></a><b>Session Initiation Protocol
(SIP)</b>: An application-layer control (signaling) protocol for creating,
modifying, and terminating sessions with one or more participants. <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_586971aa-3b65-4de3-be93-1a9756777d89">SIP</a> is defined in <a href="https://go.microsoft.com/fwlink/?LinkId=90410">[RFC3261]</a>.</p>

<p><a id="gt_c305d0ab-8b94-461a-bd76-13b40cb8c4d8"></a><b>Unicode</b>: A character
encoding standard developed by the Unicode Consortium that represents almost
all of the written languages of the world. The <a href="0c7c72f3-b621-4f80-b2ea-c5be149646ec.md#gt_c305d0ab-8b94-461a-bd76-13b40cb8c4d8">Unicode</a> standard <a href="https://go.microsoft.com/fwlink/?LinkId=154659">[UNICODE5.0.0/2007]</a>
provides three forms (UTF-8, UTF-16, and UTF-32) and seven schemes (UTF-8,
UTF-16, UTF-16 BE, UTF-16 LE, UTF-32, UTF-32 LE, and UTF-32 BE).</p>

<p><a id="gt_e767a471-c3fa-4e4b-a40c-daeb08f82a17"></a><b>user object</b>: An object of
class user. A user object is a security principal object; the principal is a
person or service entity running on the computer. The shared secret allows the
person or service entity to authenticate itself, as described in (<a href="/openspecs/windows_protocols/MS-AUTHSOD/953d700a-57cb-4cf7-b0c3-a64f34581cc9">[MS-AUTHSOD]</a>
section 1.1.1.1).</p>

<p><a id="gt_409411c4-b4ed-4ab6-b0ee-6d7815f85a35"></a><b>UTF-8</b>: A byte-oriented
standard for encoding Unicode characters, defined in the Unicode standard.
Unless specified otherwise, this term refers to the UTF-8 encoding form
specified in [UNICODE5.0.0/2007] section 3.9.</p>

<p><a id="gt_f8d6223d-5289-4966-9fc0-8ec7b7b42860"></a><b>Voice over IP (VoIP)</b>: The
use of the Internet Protocol (IP) for transmitting voice communications. VoIP
delivers digitized audio in packet form and can be used to transmit over
intranets, extranets, and the Internet.</p>

statements of optional behavior use either MAY, SHOULD, or SHOULD NOT.</p>
